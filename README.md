# Teja Portfolio

Professional portfolio website for **Bala Shiva Teja Kandimalla** — Sr. React / Node.js Developer with 10+ years of MERN/MEAN stack experience.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

This project is ready for deployment on [Vercel](https://vercel.com):

```bash
npm run build
```
