# Bala Shiva Teja Kandimalla - Portfolio

Professional portfolio website for Bala Shiva Teja Kandimalla - Sr. React/Node.js Developer with 10+ years of MERN/MEAN stack experience.

## 🚀 Features

- **Modern Tech Stack**: Built with React 19, TypeScript, and Vite
- **Responsive Design**: Fully responsive layout optimized for all devices
- **Tailwind CSS**: Beautiful, utility-first styling
- **Fast Performance**: Optimized build with Vite
- **SEO Friendly**: Proper meta tags and semantic HTML
- **Type Safe**: Full TypeScript support

## 📋 Sections

- **Hero**: Eye-catching introduction with call-to-actions
- **About**: Professional background and achievements
- **Skills**: Comprehensive list of technical skills organized by category
- **Experience**: Detailed work history with key accomplishments
- **Projects**: Showcase of featured projects with technologies used
- **Contact**: Contact form and social media links
- **Footer**: Professional footer with copyright information

## 🛠️ Tech Stack

- **Frontend Framework**: React 19
- **Language**: TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Linting**: ESLint

## 📦 Installation

\`\`\`bash
# Clone the repository
git clone https://github.com/BalaShivaTeja/teja-portfolio-new.git

# Navigate to project directory
cd teja-portfolio-new

# Install dependencies
npm install
\`\`\`

## 🏃‍♂️ Running Locally

\`\`\`bash
# Start development server
npm run dev

# The site will be available at http://localhost:5173/
\`\`\`

## 🏗️ Build

\`\`\`bash
# Create production build
npm run build

# Preview production build
npm run preview
\`\`\`

## 🧹 Linting

\`\`\`bash
# Run ESLint
npm run lint
\`\`\`

## 🎨 Customization

To customize the portfolio content, edit the following files:

- **Personal Information**: Update \`src/components/Hero.tsx\`, \`src/components/About.tsx\`, and \`src/components/Contact.tsx\`
- **Skills**: Modify the skills array in \`src/components/Skills.tsx\`
- **Experience**: Update work history in \`src/components/Experience.tsx\`
- **Projects**: Add/modify projects in \`src/components/Projects.tsx\`
- **Styling**: Adjust theme colors in \`tailwind.config.js\`
